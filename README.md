# 📊 Analyse des Ventes E-Commerce

Analyse exploratoire d'un dataset de ventes e-commerce britannique avec Python.

## Objectif
Identifier les tendances clés à partir de 541 909 transactions réelles :
- Quels produits génèrent le plus de revenu ?
- Quel mois est le plus rentable ?
- Quels pays commandent le plus ?
- À quelle heure les ventes explosent-elles ?

## Dataset
- **Source :** Online Retail Dataset (UCI Machine Learning Repository / Kaggle)
- **Période :** Décembre 2010 – Décembre 2011
- **Taille :** 541 909 transactions, 8 colonnes

## Technologies utilisées
- Python
- Pandas
- Matplotlib
- Seaborn
- JupyterLab

## Résultats clés
- **Produit star :** Regency Cakestand, (134 694 £)
- **Mois le plus rentable :** Novembre 2011 (~1.13M£)
- **Marché principal :** Royaume-Uni (6.7M£)
- **Heure de pointe :** 12h avec 1.32M£ de revenu
